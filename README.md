# Games Library

A curated repository of web-based and tactical games.

## Games Collection

### ⚓ Blackwater Command
- **Directory:** [`blackwater-command/`](./blackwater-command/)
- **Description:** Naval tactical rogue-lite & real-time authoritative multiplayer duel simulator. Features fog-of-war reconnaissance, ballistic missiles, route map campaigns, 24×24 quadrant arena, and online 20×10 tactical 1v1 duels with zero-leak information security.
- **Standalone Game:** [`blackwater-command/blackwater-command.html`](./blackwater-command/blackwater-command.html)
- **Authoritative Server:** [`blackwater-command/server/mp-server.js`](./blackwater-command/server/mp-server.js)
- **Deployment Guide:** [`blackwater-command/docs/itch-io-backend-setup-guide.md`](./blackwater-command/docs/itch-io-backend-setup-guide.md)
